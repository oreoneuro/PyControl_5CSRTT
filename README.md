# PyControl_5CSRTT
5CSRTT Task Codes for PyControl

## Acknowledgements
These protocols are adapted from the 5-CSRTT task files in
[KaetzelLab/Operant-Box-Code](https://github.com/KaetzelLab/Operant-Box-Code)
and run on [pyControl](https://github.com/pyControl/code).
